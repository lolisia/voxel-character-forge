# Voxel Character Forge

SD 체형 복셀 캐릭터를 **파츠 단위로 생성(LLM/AI)** 하고, 게임에서 **커스터마이즈 가능한 캐릭터로 조립**하는 파이프라인.

- 모든 캐릭터는 하나의 SD 스켈레톤(`sd_v1`)을 공유한다. 애니메이션은 모든 캐릭터가 재사용한다.
- 파츠는 뼈 하나에 강체로 붙는 복셀 덩어리(`.vox` + JSON 메타)다.
- 색은 역할 인덱스로 저장하고, 런타임 팔레트로 칠한다.
- 캐릭터 하나 = 파츠 ID + 팔레트를 담은 작은 JSON.

설계 배경과 상세 제안: [복셀 SD 캐릭터 생성 시스템 제안서](https://claude.ai/artifact/KNELnxunnKr91FpEQBSvaE)

## 구조

```
tools/        파츠·모션 생성 도구 (Python): 복셀 DSL, 이미지→복셀화, 검증기
unity/        Unity 런타임 (URP): Assembler, MeshCombiner, 팔레트 셰이더
parts/        슬롯별 파츠 라이브러리 (.vox + .json)
animations/   SD 스켈레톤에 리타깃된 모션
schemas/      캐릭터 정의 · 파츠 메타 · 복셀 DSL JSON 스키마
samples/      예시 캐릭터 정의
reference/    체형·스타일 레퍼런스 이미지
documents/    설계 문서
```

## 생성 경로

| 경로 | 흐름 | 용도 |
| --- | --- | --- |
| A | 텍스트 → LLM 복셀 DSL → 복셀화 → 4방향 렌더 → LLM 비평 루프 | 대부분의 파츠 |
| B | 컨셉 삼면도 → 이미지→3D → 슬롯별 복셀화 → 팔레트 양자화 | 머리카락 등 유기적 형태, 코스튬 세트 |

두 경로 모두 검증기(규격·간섭 검사)와 개발자 승인을 거쳐 `parts/`에 들어간다.
